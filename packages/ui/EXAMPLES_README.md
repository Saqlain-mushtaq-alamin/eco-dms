# Note about Example Files

The `EXAMPLE_WEB_USAGE.tsx` and `EXAMPLE_MOBILE_USAGE.tsx` files in this directory are for **documentation purposes only**. They show how to use the shared packages in your apps.

These files are **not** part of the package exports and may show TypeScript errors in the editor (since they reference other packages). This is expected and does not affect the functionality of the `@eco-dms/ui` package itself.

## How to Use

Copy the relevant code from these examples into your actual app files:
- For web app: `apps/web/src/`
- For mobile app: `apps/mobile/src/`

When used in the actual apps (which have proper path mappings configured), the imports will work correctly.
